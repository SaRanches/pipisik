# Маленькая вселенная для Викусика

Готовый статический сайт для GitHub Pages. Сборка, Node.js и сервер не нужны.

## Как опубликовать

1. Создай на GitHub новый публичный репозиторий, например `little-universe`.
2. Выбери **Add file → Upload files** и загрузи СОДЕРЖИМОЕ этой папки в корень репозитория. Файл `index.html` должен лежать сразу в корне, а не внутри ещё одной папки.
3. Сохрани загрузку кнопкой **Commit changes**.
4. Открой **Settings → Pages**.
5. В **Build and deployment → Source** выбери **Deploy from a branch**.
6. Выбери ветку **main**, папку **/(root)** и нажми **Save**.
7. Дождись публикации. Готовая ссылка появится в разделе Pages; обычно это `https://ТВОЙ-ЛОГИН.github.io/little-universe/`.

После публикации сайт работает с телефона, даже когда твой компьютер выключен.

## Файлы

- `index.html` — страница, тексты и письмо.
- `styles.css` — оформление и адаптация под телефон.
- `app.js` — письмо, звуки, тёплые сообщения и сохранение прогресса.
- `games.js` — три мини-игры.
- `icon.svg` — иконка сайта.
- `.nojekyll` — отключение обработки Jekyll; при загрузке через браузер скрытый файл может не отображаться, для этих HTML/CSS/JS-файлов это не мешает публикации.

Прогресс хранится в браузере посетителя. Шрифты загружаются из Google Fonts; если сервис недоступен, используются запасные системные шрифты.

## Как обновлять

Замени нужные файлы в репозитории и сохрани изменения. GitHub Pages обновит сайт автоматически. При необходимости обнови страницу на телефоне.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
